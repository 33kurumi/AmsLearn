# 高等数学学科知识图谱（KB-5 知识库版）

## 使用说明
本图谱与大纲、讲义、题库共用 kp001~kp067 编号，每条记录一段，描述单个知识点的前置依赖（pre_kp_id）、后继衔接（next_kp_id）与关联强度（strength，0~1）。供智能体进行薄弱点根因分析（找出前置缺口）与学习路径推荐（按依赖顺序规划复习）。关键词精准匹配检索。
