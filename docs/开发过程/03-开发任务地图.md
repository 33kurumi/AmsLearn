## 5. 功能范围

### 本组选题

个性化学习导师（高等数学考研辅导）：学生侧知识库答疑、诊断、计划与分层练习、错题复盘；教师侧班级配置、学情分析、知识库管理。

### 必做核心功能

1. 知识库答疑（结合教师配置与学情，引导式不给答案）；
2. 知识诊断闭环（出题→批改→报告→掌握度/错题同步）；
3. 教师配置边界即时生效（难度上限/知识范围/禁用话题/回答模式）；
4. 学习计划与分层练习（A/B/C、只给思路）；
5. 教师班级学情分析（与学生记录同源）。

### 暂不实现（P2 迭代）

1. 持久化向量库（v1.1 已落地 LangChain `InMemoryVectorStore` + 本地 Embeddings；v1.2 已支持可插拔 OpenAI 兼容 embedding provider，后续可换 Chroma/FAISS 持久化）；
2. **v1.3 已把「图片/公式图片答疑」从暂不实现提升为已实现**：图片先转文字再走文字答疑（`docs/开发过程/01` §11.4），图片本身不落库、不进多轮上下文。

> v1.2 已把原「多轮对话上下文持久化」从暂不实现提升为已实现（`conversation` 表 + `/api/conversations`，见 `docs/开发过程/01` §10.7）。

### 加分功能

1. real 默认、mock 降级（有 key 走 DeepSeek，无 key 也能演示）；
2. 一键启动/停止/环境检查/验收脚本；
3. KaTeX 公式渲染与资料来源展示。
4. **v1.2** 学生可填自己的 DeepSeek Key（AES/GCM 加密存储、只回掩码）；
5. **v1.2** 顶栏 AI 模式徽标（real · 模型 · 系统 Key / 我的 Key / mock）与来源去重展示。
6. **v1.3** 答疑支持上传题目图片自动转文字（硅基流动 Qwen3-VL-8B，约 6 秒/张）。
7. **v1.3** 教师配置的暂缓/超纲内容不再硬拦截，改为「前置自测 3 题 → 通过后三步教学」，兼顾教学边界与循序渐进。
