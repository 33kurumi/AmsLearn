# 首次运行检查

> 第一次拿到项目时按本文件走一遍（约 20 分钟）。完整部署说明、常见问题与验收脚本见 `docs/开发过程/06-部署与运行手册.md`；接口字段见 `docs/开发过程/01-接口约定.md`；文档总索引见 `README.md`。

## 1. 环境要求

| 工具 | 建议版本 | 检查命令 | 说明 |
| --- | --- | --- | --- |
| Node.js | 22 LTS（≥20） | `node -v` | 前端构建 |
| npm | 10+ | `npm -v` | 随 Node 安装 |
| JDK | 17 | `java -version` | Java 服务；PATH 中的 java 必须是 17 |
| Maven | 用项目自带 Wrapper | `business-service\mvnw.cmd -v` | 无需全局安装 |
| Python | 3.12（3.11 可用） | `python --version` | AI 服务 |
| Git | 2.x | `git --version` | 版本管理 |

先双击 `scripts\检查环境.bat`：会检查上述工具、三个端口（8000/8080/5173）、AI 虚拟环境与 `.env`、前端依赖。某项显示「缺少」时先修该环境，不要靠复制项目绕过。

## 2. 启动顺序（统一端口，不得私改）

| 顺序 | 服务 | 端口 | 一键脚本 | 健康检查 |
| --- | --- | --- | --- | --- |
| 1 | AI 智能问答 | 8000 | `scripts\启动AI服务.bat` | <http://localhost:8000/health> |
| 2 | Java 业务 | 8080 | `scripts\启动Java服务.bat` | <http://localhost:8080/api/health> |
| 3 | Vue 前端 | 5173 | `scripts\启动Vue前端.bat` | <http://localhost:5173> |

一键启动 `scripts\启动全部服务.bat`；停止 `scripts\停止全部服务.bat`。

### 2.1 前端

```bat
cd frontend
set npm_config_cache=..\.npm-cache
npm install
npm run dev
```

浏览器访问 <http://localhost:5173>。**沙箱/受限环境注意**：npm 默认缓存目录可能不可写（报 `EPERM` 或卡住），务必先设 `npm_config_cache` 到工作区（脚本已设）。

### 2.2 Java 业务服务

```bat
cd business-service
mvnw.cmd spring-boot:run
```

双击 `scripts\启动Java服务.bat` 会自动检测 JDK 17、推导 `JAVA_HOME`、设置 UTF-8 编码。首次启动自动建表并写入演示数据（H2 文件库，无需安装 MySQL），数据在 `business-service/data`。健康检查 <http://localhost:8080/api/health>，H2 控制台 <http://localhost:8080/h2-console>（JDBC URL `jdbc:h2:file:./data/student-project;AUTO_SERVER=TRUE`，用户 `sa`，空密码）。

### 2.3 AI 服务

```bat
cd ai-service
python -m venv .venv
.venv\Scripts\python.exe -m pip install --no-cache-dir --disable-pip-version-check -r requirements.txt
copy .env.example .env
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- `.env` 中 `DEEPSEEK_API_KEY` 填 DeepSeek key；`AI_MODE=auto` 下**有 key 默认走真实（`mode=real`）**，不填自动降级 mock，**无 key 也能完整演示**；
- **pip 卡死坑**：默认缓存在用户目录被拒绝会表现为卡住，用上面的 `--no-cache-dir` 命令，并先把 `$env:TMP` 指到工作区（详见 docs/开发过程/06 §4.1）；
- 健康检查 <http://localhost:8000/health>，接口文档 <http://localhost:8000/docs>。

## 5. 常见问题速查

| 问题 | 处理 |
| --- | --- |
| 找不到 `package.json` / `pom.xml` | 终端目录不对，先 `cd` 到对应工程目录 |
| 端口被占用 | 运行 `scripts\停止全部服务.bat`；仍占用用 `netstat -ano` 查 PID |
| Java 版本不对 | `java -version` 与 `mvnw.cmd -v` 都应为 17+ |
| npm `EPERM/EACCES` 或卡住 | 设 `npm_config_cache` 到工作区后重装 |
| pip 卡住 | `--no-cache-dir` + `TMP` 到工作区（docs/开发过程/06 §4.1） |
| 页面 401/跳登录 | 重新登录；确认 Java 已启动 |
| 中文乱码 | 脚本已 `chcp 65001`；手动启动先执行该命令 |

更多问题（H2 锁、Maven Wrapper 下载、AI 模式切换、公式渲染等）见 `docs/开发过程/06-部署与运行手册.md` §9。
